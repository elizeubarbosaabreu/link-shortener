# Link Shortener - elizeubarbosa.com.br

Repositório de dados do encurtador de links do site [elizeubarbosa.com.br/link](https://www.elizeubarbosa.com.br/link/).

## Uso

O site busca `links.json` via GitHub raw content para redirecionar os links curtos.

CLI local: `link-shortener add <url> [--code <código>]`
